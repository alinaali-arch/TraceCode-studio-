    TraceLang reference
    
            
    TraceLang is a small Python-style programming language made for this project. It is not the Linux or Windows shell. Programs are indented instead of using braces, and every program is wrapped in start and end.
    

            
    Your first program
    

    start
name: string = "Alina"
age: int = 20
show "Hello"
show name
show age + 10
end
    

            
    Variables and types
    
            
    
              
    FormMeaning
    
              
    x: int = 10declare with a type and an initial value
    
              
    x: floatdeclare without a value (must be assigned before it is read)
    
              
    x = x + 1assign a new value
    
              
    typesint, float, string, bool
    
              
    int to floatallowed implicitly. float to int is a type error.
    
            
    

            
    Input and output
    

    write name: string     # declare and read a line
write age: int         # read an integer
write total            # read into an existing variable
show name              # print any value followed by a new line
    
            
    write reads int, float, bool (true or false) and string.
    

            
    Operators (highest binds tightest)
    
            
    
              
    GroupOperatorsNotes
    
              
    unary-xint or float
    
              
    multiply*  /  %left to right; % needs int
    
              
    add+  -left to right; no string concatenation in v1
    
              
    compare== != < > <= >=non-associative: a < b < c is an error
    
              
    notnot xbool only
    
              
    anda and bshort-circuit, bool only
    
              
    ora or bshort-circuit, bool only
    
            
    

            
    Conditions and loops
    

    if marks >= 50:
    show "Pass"
elif marks >= 40:
    show "Weak pass"
else:
    show "Fail"

i: int = 1
while i <= 5:
    show i
    i = i + 1

for k in 1 to 3:       # inclusive upper bound
    show k
    

            
    Functions
    

    function add(a: int, b: int) -> int:
    result: int = a + b
    return result

show add(10, 20)

function report(name: string):    # no return type
    show name
    
            
    Functions are declared at the top level. They can read globals, but to change a value they must return it.
    

            
    Scope
    
            
    Each if, else, while, for and function has its own scope. An inner variable may reuse an outer name. Using a name that was not declared, or declaring one twice in the same scope, is an error.
    

            
    Comments
    
            
    A # starts a comment that runs to the end of the line. Indent with spaces only.

      TraceCode Studio
      
        
      A visual compiler workbench for the TraceLang programming language.
      
      
      
      
    
      

    
      Write a TraceLang program and watch it pass through every compiler phase: lexical analysis, syntax analysis, semantic checks, symbol table, intermediate code, optimization and x86-64 code generation. The program is then assembled, linked and run on this machine.
      

    
      Architecture
      
    
        
      
      1. Lexer (Flex): characters to tokens, with INDENT and DEDENT
        2. 
      
      2. Parser (Bison): tokens to an abstract syntax tree (AST) with operator precedence
        3. 
      
      3. Semantic analysis: types, scopes and definite assignment
        4. 
      
      4. Symbol table and three-address code (TAC)
        5. 
      
      5. Optimizer: folding, propagation, simplification, common subexpressions, dead code
        6. 
      
      6. Code generator: NASM x86-64 assembly, assembled with NASM and linked with ld
        7. 
    
      

    
      Technology
      
    
      
      C11FlexBison
      NASMGNU ldPython 3
      HTML / CSS / JavaScriptGraphviz
